# Origen y características de los datos

Los datos utilizados en esta práctica son inventados y se han creado para realizar las pruebas de la asignatura de Sistemas Big Data. No se han utilizado datos reales de clientes.

---

## 1. Protección de datos

- Los usuarios y productos son de ejemplo y no representan personas ni compras reales.
- Los correos electrónicos utilizados son ficticios.
- Los productos, las categorías y los usuarios tienen identificadores como `PROD001`, `CAT001` y `USR001`, para poder distinguirlos fácilmente.
- Solo se guardan los datos necesarios para probar el funcionamiento de la base de datos.

## 2. Cantidad y tipo de datos

- **Productos:** se incluyen ejemplos de productos de una tienda online, con su nombre, precio, marca, características, variantes y stock.
- **Categorías:** guardan información para organizar los productos y facilitar las búsquedas.
- **Usuarios:** contienen datos básicos ficticios para probar las relaciones con las reseñas.
- **Reseñas:** incluyen puntuaciones y comentarios de ejemplo. Se guardan dentro de los documentos de los productos.

Los datos son suficientes para probar las búsquedas, las actualizaciones, los índices y las consultas de agregación realizadas durante la práctica.
